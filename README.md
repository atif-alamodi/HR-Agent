# فريق وكلاء الموارد البشرية

لوحة تفاعلية فيها سبعة وكلاء متخصصين في الموارد البشرية، تتحدث مع كل وكيل مباشرةً، مدعومة بالذكاء الاصطناعي. تعمل كموقع ثابت على GitHub Pages، وتتصل بالنموذج عبر وسيط Cloudflare Worker يخفي المفتاح.

## الوكلاء
- **مستشار نظام العمل**: الامتثال والعقود والإنهاء والاستقالة ومكافأة نهاية الخدمة، مسنود بمواد نظام العمل السعودي (م/44 النافذ في 19/2/2025).
- **أخصائي التوظيف والسعودة**: الأوصاف الوظيفية وأسئلة المقابلات وخطط نطاقات.
- **مفاضل السير الذاتية**: يقرأ السير (PDF و DOCX و TXT) ويفاضل بين المرشحين بموضوعية مع درجات وترتيب نهائي.
- **أخصائي علاقات الموظفين**: التظلمات والإجراءات التأديبية وخطابات الإنذار.
- **أخصائي التعويضات والمزايا**: هيكلة الرواتب وحساب التأمينات ومكافأة نهاية الخدمة وخطط الحوافز.
- **محلل الموارد البشرية**: تعريف وحساب المؤشرات وتصميم لوحات المعلومات.
- **كاتب الوثائق والمراسلات**: الخطابات والشهادات والتعاميم بصيغة رسمية.

## المزايا
- مفاضلة وقراءة السير الذاتية مع وصف وظيفي اختياري.
- رفع مرفقات لكل الوكلاء: تُقرأ ملفات PDF و DOCX و TXT داخل المتصفح، وتُرسل الصور للنموذج كرؤية.
- حفظ المحادثات محليًا في المتصفح، وواجهة عربية RTL تعمل على الجوال والحاسوب.

## الملفات
- `index.html` التطبيق كاملًا (بدون خطوة بناء).
- `worker.js` وسيط Cloudflare Worker.
- `wrangler.toml` إعداد النشر للوسيط.

## خطوات النشر

### 1) نشر الوسيط (Cloudflare Worker)
```bash
npm install -g wrangler
wrangler login
wrangler deploy
wrangler secret put ANTHROPIC_API_KEY     # الصق مفتاح Anthropic
wrangler secret put APP_TOKEN             # اختياري: أي رمز سري تختاره
```
انسخ رابط الـ Worker الظاهر بعد النشر، مثل:
`https://hr-agents-proxy.your-name.workers.dev`

> بديل بدون Worker: يمكن تشغيل الأداة بوضع المفتاح المباشر من شاشة الإعدادات، لكنه يكشف المفتاح في المتصفح فلا يصلح لنسخة منشورة للعموم.

### 2) النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع فيه `index.html`.
2. من Settings ثم Pages اختر الفرع `main` والمجلد الجذر `/ (root)`.
3. سيظهر الموقع على `https://<username>.github.io/<repo>/`.

### 3) الربط
افتح الموقع، اضغط أيقونة الإعدادات، ثم:
- الصق **رابط الـ Worker**.
- إن فعّلت `APP_TOKEN` في الخادم، الصق القيمة نفسها في **رمز التطبيق**.
- تحقق من **اسم النموذج** (الافتراضي `claude-sonnet-4-6`) وغيّره إن لزم.
- احفظ.

## ملاحظات
- لتقييد استخدام الـ Worker لنطاق موقعك فقط، استبدل `*` في `Access-Control-Allow-Origin` داخل `worker.js` برابط صفحتك.
- ملفات PDF و DOCX تتحول إلى نص خفيف فتبقى ضمن سياق المحادثة عند المتابعة. الصور لا تُحفظ بعد إعادة التحميل لتفادي امتلاء التخزين المحلي.
- مفاضلة السير تلتزم بالعدالة وعدم التحيز للاسم أو الجنس أو الجنسية أو العمر.
